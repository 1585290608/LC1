# LC1 Draft3B — 简化经济分析

日期：2026-11-05。状态：**限定范围的数值研究完成；设备报价、商业合同和真实并网许可仍未验证。**

## 主要结论

在所声明的真实2026年GBP成本假设、£0.24/kWh购电和3%实际折现率下，P1相对P0R具有正的20年现值节约。零外送案例节约£222,269.95，假设允许20kW外送且£0.05/kWh结算时节约£223,568.37。因此基准结论并不依赖售电收入，但依赖成本、风电资源和电价假设，不能作为真实项目投资承诺。

E20/R30基准：混合系统设备/场地CAPEX £529,350.00，另有与P0R相同的£2,700柴油周转库存；年运行成本£53,564.62，P0R为£100,540.40。折现持续回本约12.24年；按离散年末现金流观察为第13年。低电价或仅实现60%模型风电量时，20年内不能实现折现持续回本。

P3把储备SOC从30%提高至70%，在E20下增加约£1,007.75/年。它是经济性与应急库存的权衡，不是已验证的断电供电能力提升。

## 2. 公平的初末SOC与电力约束

混合系统统一PV50/Wind50/BESS300/PCS90/DG100/UPS30kW15min；一个DG，2000L油箱库存，正常并网DG和UPS输出均为0。P0全购电，不设置虚构BESS SOC；P0R有DG/UPS/油箱投资和O&M，正常年电量与P0相同，未模拟停电或货币化韧性收益。

Battery物理边界0.1–0.9，方向效率各0.8944，PCS90kW，严格禁止同一小时充放同时发生。正常RE先供负荷、富余充电；缺口由高于选定储备阈值的电池放电，余量购电。不可售电的RE余量显式弃电，外送只有直接RE剩余，电池/DG不售电。100kW输入上限继承自旧LC1说明性场景，但本轮真正执行；0/20kW外送上限也执行，均不是已取得的DNO许可。

**年初和年末SOC都等于0.70。** 事前登记的最后48小时终端管理把充电目标和放电底线设为70%，优先RE，并在100kW购电剩余容量、90kW PCS及效率约束内付费从电网补足。若输入库存高于70%，只能在实际负荷缺口时放电；若无法达到目标则隔离失败，绝不重置SOC。所有补能逐时计量入账，无P2电价套利。年末控制窗不是根据有利结果搜索出来的参数。

基准E20/R30的实际终端购电充电量134.168157kWh，已包含在总年购电165,367.261305kWh和购电成本中。旧Draft2年度SOC0.70→0.30、购电165,233.093148kWh只能作历史参照，不直接用于本轮NPC。本轮多购入134.168157kWh来恢复120kWh DC库存；不修改旧raw数据。

## 4. NPC、回本与主结果

年购电费用=购电kWh×价格；条件售电收入=实际限额内外送kWh×£0.05。年运行成本=购电−售电+O&M+共同固定费，不含年0投资、更换和库存回收。NPC逐年计算：`Σ(year0..20)现金成本/(1.03)^year`，年末支付，每个更换费用只计一次。所有财务值为固定真实2026GBP，不计额外税、补贴、融资利息、通胀或价格上调。

## 7. 验证、图表与研究意义

原15项修复物理测试及新增测试合计28项通过，0失败。12个8760h案例共105,120小时独立从CSV重算，最大单小时AC残差1.776e-14kWh、DC残差2.132e-14kWh；初末SOC、PCS、购/售电限额、状态连续性、无同时进出/充放和所有负荷服务都核查。16个经济计算的CAPEX/O&M、更换、折现现金流、闭式NPC及回本由独立模块复算，最大NPC差£1.397e-09。独立进程12条逐时trace字节一致，16经济结果复现；没有需要隔离的主案例或被隐藏的不利经济结果。

三张要求图均由已准入数据生成：CAPEX与年运行费用、20年折现成本、SOC储备年成本；每张有CSV来源、可编辑SVG、矢量PDF、600dpi PNG。初次渲染的过长纵轴标签已修正，旧版留在versions/initial_export；最终PDF实际渲染并审阅。依赖安装首次缺tzdata的日志也保留；补齐原先已锁定的tzdata后成功，不影响研究结果。

本轮加强的是公平初末储能库存条件下的**条件性技术经济推论**：风光自用可减少购电，储备有可量化的年度成本，售电收益在此基准较小，成本回收对电价和风电实现率敏感。没有证明PV75/Wind75最优，没有新做MDT/HOMER经济验证、设备验证、保护、UPS或孤岛可靠性试验，也没有运行Draft3C或撰写IEEE LaTeX。
