## Remake 版本

早期模型的 V1、V2 由 Draft 2 的模型版本映射和代码哈希追溯。
V3–V11 的入口是 V11 封存项目中留存的工程报告。V12–V16 有各自的项目目录。
以下条目均已核对本地原件路径。

| 版本 | 研究目标 |
| --- | --- |
| V3 | 物理与指标审核、工程验收关口 |
| V4 | 代表性系统设计与设备证据 |
| V5 | 储能 SOC 验收关口 |
| V6 | 多目标比较与跨工具验证边界 |
| V7 | 验证证据审核 |
| V8 | 条件韧性与模型限制 |
| V9 | 运行发电机故障与成网切换 |
| V10 | 受控 Python 校准与原生 MDT 对比准备 |
| V11 | 工程证据与模型审核 |
| V12 | 年度能量账独立复核与便携运行 |
| V13 | 原生 MDT 24 小时案例执行 |
| V14 | 受控恒定负荷柴油机对比 |
| V15 | 混合系统的时钟、储能与能量对比 |
| V16 | SOC、关键负荷优先级及最终研究审核 |

V13 的原生结果表示已执行和回读。V14 的正式对比范围限于恒定负荷、柴油机单独供电的诊断案例。
V15 的混合系统比较仍为 PARTIALLY_COMPARABLE。具体结论以各版本报告为准。
