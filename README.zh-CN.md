# LC1 Microgrid

Cardiff University EN3400 研究项目，分析代表性学术微电网的能量核算、孤岛韧性和并网经济性。

- [Initial Draft](Initial%20Draft/README.md) 是冻结的历史 GitHub 版本，原文件与结果保持原字节及目录内相对路径。
- [Week7Remake](Week7Remake/README.md) 包含 Stage 0–7 实现和 Stage 8 可公开验证证据。迁移审阅并合并后，日常开发在此目录内进行。
- [研究对比](RESEARCH_COMPARISON.md) 和 [变更日志](CHANGELOG.md) 说明模型假设、验证边界和跨版本差异。

两个版本各自在自己的目录运行。原始 MDT 文件、第三方文献、专用数据库和大型实验结果保存在本地研究档案。120 人营地、7 辆代表性 EV、设备选型、电价及并网容量均为建模假设。
