# LC1 Sennybridge climate source pack

Copy this folder into the corresponding `Week7Remake/research_evidence/climate_reference_validation/` directory in the local LC1 repository.

- `CLIMATE_SOURCE_RECORD.md` — source URLs, primary station evidence, correct location-specific URL, NASA comparison, Fourier check, and validation limitations.
- `SENNYBRIDGE_MET_OFFICE_1991_2020_MONTHLY.csv` — transcribed official Met Office 1991–2020 station monthly measurements and explicitly derived columns.
- `SENNYBRIDGE_MET_OFFICE_VS_NASA_2025_MONTHLY.csv` — actual archived NASA POWER 2025 monthly means and cross-context comparisons.

This is **read-only source documentation**, not a new LC1 simulation or change to existing equipment/load assumptions.

Not uploaded to GitHub and not installed into your Windows worktree by this pack.
